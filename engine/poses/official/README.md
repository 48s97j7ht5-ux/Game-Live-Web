# Official pose experiment assets

Browser pose experiment uses original assets rather than hand-authored vertex deformations.

- `anny-t-pose.json`: NAVER Anny, Apache-2.0 project data / bundled MPFB2-derived data.
- `callharvey3d_sittingdefault.bvh`: callharvey3d, MakeHuman Community poses01, CC0.
- `callharvey3d_sittingnatural.bvh`: callharvey3d, MakeHuman Community poses01, CC0.
- `anrico_sitting03.bvh`: Anrico, MakeHuman Community poses01, CC0.

Sources:
- https://github.com/naver/anny
- https://static.makehumancommunity.org/assets/assetpacks/poses01.html
