# MakeHuman hair assets

Vendored from `emberlightstudios/Humentity`, which contains the MakeHuman system assets released as CC0.
Binary/LFS-backed OBJ files are resolved through Git LFS before copying, so the browser receives real mesh data rather than LFS pointer text.

Included:
- bob01
- long01
- ponytail01
- short02
- braid01
