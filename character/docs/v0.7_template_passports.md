# Character Renderer v0.7 — паспорта шаблонов

Цель v0.7: заменить слабые маски v0.6 на трассированные по эталону шаблоны с минимальным количеством разрезов и контролируемой деформацией.

## 1. head_neck
- Размер маски: ориентир 64×72 px в исходной сетке 240×400.
- Anchor: `head_center`, `neck_base_center`.
- Overlap: низ шеи заходит в `torso_core` на 4–6 px.
- Деформация: `scaleY` ±3%, `scaleX` ±2%.
- Не деформировать: лицо, челюсть, ширину шеи отдельно.
- Назначение: цельная голова + шея без кукольного стыка.

## 2. torso_core
- Главный шаблон проекта.
- Размер маски: ориентир 108×170 px.
- Зона: от основания шеи до начала расхождения ног.
- Anchor: `neck_base_center`, `left_shoulder_socket`, `right_shoulder_socket`, `pelvis_center`, `left_hip_socket`, `right_hip_socket`.
- Overlap: верх рук под плечевой пояс 8–12 px; верх ног под таз 10–14 px.
- Деформация:
  - shoulders → верхние 25% маски;
  - waist → средние 30–65%;
  - hips → нижние 35%;
  - height → вертикально максимум ±4%.
- Не деформировать: ключицы, центр груди, пупок, паховую центральную линию.

## 3. left_arm / right_arm
- Размер: ориентир 32×156 px.
- Anchor: `shoulder_socket`, `elbow_hint`, `wrist_hint`.
- Overlap: верх руки скрывается под `torso_core` на 8–12 px.
- Деформация: длина ±5%, ширина ±8%.
- Не деформировать: кисть отдельно.
- Рука хранится цельной от плеча до пальцев.

## 4. left_leg / right_leg
- Размер: ориентир 44×190 px.
- Anchor: `hip_socket`, `knee_hint`, `ankle_hint`.
- Overlap: верх бедра скрывается под `torso_core` на 10–14 px.
- Деформация:
  - height → длина до ±8%;
  - hips → верхние 35% ширины;
  - calf width → пока фиксировано.
- Не деформировать: колено как отдельный сустав.

## 5. left_foot / right_foot
- Размер: ориентир 28×24 px.
- Anchor: `ankle_joint`.
- Overlap: 2–3 px под голенью.
- Деформация: практически нет, максимум ±2%.

## 6. body_shading_v2
- Overlay-слой, привязанный к зонам `torso_core`, `arms`, `legs`.
- Содержит: ключицы, грудь, боковые тени талии, живот, таз, внутреннюю линию бёдер, колени, икры, лодыжки.
- Масштабируется вместе с родительской частью локально, не глобально.

## 7. face_v2
- Anchor: `face_center` внутри `head_neck`.
- Деформация: отсутствует.
- Отдельный слой для будущих эмоций.

## 8. underwear_top_v2
- Parent: `torso_core`.
- Anchor: `chest_center`.
- Следует только верхней половине `torso_core`.
- Не влияет на геометрию тела.

## 9. underwear_bottom_v2
- Parent: `torso_core`.
- Anchor: `pelvis_center`.
- Следует нижней части `torso_core` и краям верхних бёдер.

## 10. hair_back / hair_front
- Parent: `head_neck`.
- `hair_back` рисуется до тела.
- `hair_front` — после лица/тела.
- Деформация тела на них почти не влияет.

## Политика деформации
- Не тянуть весь спрайт целиком.
- Деформировать только локальные полосы по вертикали.
- Ограничить значения, чтобы не ломать пиксельный рисунок.
- Для сильных изменений формы в будущих версиях использовать смену базового шаблона, а не экстремальную деформацию.
